# SDL Framebuffer

A low-level graphics project written in C using the SDL3 library.

## Prerequisites

- Basic understanding of C programming.
- Understanding of low-level graphics concepts is recommended.
- SDL3 library must be installed on your system.

## Installation

Clone this repository into the following location:

```bash
git clone https://github.com/avinashkrishna07/sdl-framebuffer.git /opt/homebrew/opt/sdl3/include/SDL3/sdl-framebuffer
```

## Requirements

Make sure SDL3 is installed and available before building or running the project.
